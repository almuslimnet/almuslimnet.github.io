Основные способы словообразования в английском языке

Английское словообразование — процесс создания новых слов с использованием приставок (prefixes), суффиксов (suffixes) и основ (roots).

1. Аффиксация — добавление морфем (приставок, суффиксов) 
к корню. Аффиксы меняют значение или часть речи слова.

*   Префиксы (Приставки) —  добавляются перед корнем слова 
и изменяют его значение, но не часть речи:
    *   un- / in- / im- (отрицание): 
    possible → impossible (возможный → невозможный),
    correct → incorrect. 
    *   dis- (отрицание/разделение): 
    agree → disagree (соглашаться → не соглашаться)
    like → dislike (нравиться → не нравиться), 
    connect (соединять) → disconnect (отсоединять).
    *   re- (повтор, снова): 
    write → rewrite (писать → переписывать), 
    build → rebuild (строить → перестраивать).
    *   mis- (неправильно): 
    understand → misunderstand (понимать → неправильно понять).
    *   pre- (до, заранее):
    pay (платить) → prepay (предоплата), 
    view → preview (просмотр → предварительный просмотр).
    *   over- (сверх, чрезмерно): 
    eat (есть) → overeat (переедать)
     [Да упасёт Аллах верующих от переедания и голода.], 
    work → overwork (работать → перерабатывать).


* Суффиксы добавляются к концу слова и часто меняют часть речи:

    *   Существительные:
        *   -er / -or (деятель; инструмент): 
        work → worker (рабочий), 
        teach → teacher (учить → учитель).
        *   -tion / -sion / -ment (процесс или результат): 
        inform → information (информировать → информация), 
        decide → decision (решать → решение), 
        develop → development (развивать → развитие).
        *   -ness / -ity (качество, состояние): 
        happy → happiness (счастливый → счастье), 
        kind (добрый, прил.) → kindness (доброта, сущ.).
        active → activity (активный → активность).
        
    *   Прилагательные:
        *   -able / -ible (способный, могущий, возможный):
        read → readable (читать → читаемый), 
        access → accessible (доступ → доступный).
        *   -ful (наполненный): 
        beauty → beautiful (красота → красивый).
        *   -less (без, не имеющий): 
        hope → hopeless (надежда → безнадежный).
        * -ing (процесс или действие): 
        run (бежать) → running (бег), 
        read → reading (чтение).
        
    *   Глаголы:
        * -ed (прошедшее время, страдательный залог): 
        finish → finished (закончил, законченный).
        * -en: dark (темный) → darken(темнеть).

    *   Наречия:
        *   -ly (образует наречие от прилагательного): 
        quick → quickly (быстрый → быстро), 
        happy → happily (счастливый → счастливо).

2. В английском языке очень распространена 
смена части речи без изменения формы слова:
*   to email (гл.) → an email (сущ.) 
(отправить электронное письмо → электронное письмо)
*   a call (сущ.) → to call (гл.) (звонок → звонить)
*   clean (прил.) → to clean (гл.) (чистый → чистить)
*   a drink (сущ.) → to drink (гл.) (напиток → пить)
*   text (сущ.) → to text (текст → писать сообщение).

3. Слияние слов в одно, когда два или 
более корня образуют новое слово. 
Новое слово может быть по написанию слитным, 
через дефис или раздельным.
*   tooth + brush = toothbrush (зубная щетка)
*   black + board = blackboard
(чёрный + доска = чёрная/классная доска)
*   speak + up = speakup (говори громче)
*   rain (дождь) + bow (лук) = rainbow (радуга)
*   foot + ball = football (футбол)
*   lap (колени) + top (верх) = laptop (ноутбук)
*   well + known = well-known (хорошо известный)
*   sun (солнце) + flower (цветок) = sunflower (подсолнух)
*   high (высокий) + way (путь) = highway (шоссе)
*   book(книга) + store(магазин) = bookstore(книжный магазин)

4. Изменение основ (root change)
Иногда слово меняется за счёт модификации основы.
*   strong → strength (сильный → сила)  
*   choose → choice (выбирать → выбор)

5. Слияние частей двух слов
Части двух слов объединяются для образования нового слова. 
Обычно берутся начало одного слова и конец другого.
*   smoke (дым) + fog (туман) = smog (смог)
*   motor (мотор) + hotel (отель) = motel (мотель)

Эти методы активно используются в английском языке 
для образования новых слов. 

Изучайте группы однокоренных слов.

Например, от глагола "to create" (создавать) образуется:
*   creation (сущ. — создание, творение)
*   creative (прил. — творческий)
*   creatively (нар. — творчески)
*   creator (сущ. — создатель)
*   creativity (сущ. — креативность)

И вот ещё пример употребительного слова "to use":
• use (использовать)
• user (пользователь) — суффикс -er
• useful (полезный) — суффикс -ful
• useless (бесполезный) — суффикс -less
• reuse (использовать повторно) — приставка re-
• misuse (неправильное использование) — приставка mis-
• usage (использование, употребление) — суффикс -age

При понимании этих принципов, видна структура слова. Встретив незнакомое слово, например, "unbreakable", можно разложить его: un- (не) + break (ломать) + -able (способный) = "неломаемый". Это ускоряет обучение и понимание.
