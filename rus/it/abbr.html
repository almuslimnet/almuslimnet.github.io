Software — программное обеспечение. Программы и данные, выполняемые на компьютерах и устройствах.

desktop
   
Desktop — настольный ПК. Стационарный персональный компьютер для использования на рабочем столе.
   
VGA
   
Video Graphics Array — видеографическая матрица. Старый стандарт видеоинтерфейса и разрешения для мониторов и графических карт.
   
USB
   
Universal Serial Bus — универсальная последовательная шина. Широко используемый стандарт подключения периферии и передачи данных/питания.
  
     

Linux команды

 
   
mkdir
   
make directory — создать каталог. Создаёт один или несколько новых каталогов в файловой системе.
   
ls
   
list — список. Выводит список файлов и каталогов в указанной директории; поддерживает варианты отображения и сортировки.
   
echo
   
echo — вывод. Выводит переданный текст или значения переменных в стандартный вывод; часто используется в скриптах.
   
chmod
   
change mode — изменить режим. Меняет права доступа к файлам и каталогам для владельца, группы и остальных.
   
su
   
substitute user или switch user — сменить пользователя. Позволяет временно выполнять команды от имени другого пользователя, часто root.
   
wget
   
web get — загрузчик из интернета. Утилита для скачивания файлов по протоколам HTTP, HTTPS и FTP из командной строки.
