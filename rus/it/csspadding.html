Ширина элемента

На веб-странице нужны поля справа и слева от текста, но из-за них на мобильных устройствах концы строк уходят за край экрана. Как это избежать посредством HTML и CSS?

Первое и главное

Используйте box-sizing: border-box

По умолчанию ширина элемента не включает padding и border, из-за чего ширина блока становится больше, чем указано в width. Чтобы padding учитывался внутри ширины, добавьте: 

* {
  box-sizing: border-box;
}

Это позволит задать, например, width: 100% и иметь padding внутри этой ширины.

Связанные вещи

Сделайте адаптивные отступы через padding и max-width

.container {
  max-width: 600px; /* максимальная ширина для больших экранов */
  margin: 0 auto;   /* центрируем блок */
  padding-left: 15px;
  padding-right: 15px;
}

Такой подход даст отступы слева и справа, но блок не выйдет за пределы экрана.

Используйте медиазапросы для уменьшения отступов на мобильных

@media (max-width: 480px) {
  .container {
    padding-left: 10px;
    padding-right: 10px;
  }
}

Или вообще убрать поля на очень узких экранах.

Используйте width:100%; и внутренние отступы

Например: 

.text-block {
  width: 100%;
  padding-left: 20px;
  padding-right: 20px;
  box-sizing: border-box;
}

Это позволит блоку занимать всю ширину родителя, а padding создаст внутренние поля, не выходящие за экран.

Проверьте мета-тег viewport в HTML

Очень важно иметь в head:
meta name="viewport" content="width=device-width, initial-scale=1"
Без этого мобильные браузеры могут масштабировать страницу неправильно.
