==========================================
   HTML‑теги, связанные с тегом <ruby>,
   их назначение, примеры и замечания.
==========================================

Основные теги
- <ruby>
  - Контейнер для ruby‑аннотаций. Окружает базовый текст и связанные с ним аннотации.
  - Размещение: как правило — внутри фразового контента (inline).
  - Пример: <ruby>漢<rt>かん</rt>字<rt>じ</rt></ruby>

- <rt> (ruby text)
  - Сам текст аннотации (фури́гана, произношение, краткое пояснение).
  - Показывается над (или под) исходным текстом в поддерживающих UA.
  - Должен быть дочерним элементом <ruby> (или внутри <rtc>).
  - Пример: <rt>かん</rt>

- <rp> (ruby parenthesis)
  - Запасной (fallback) контент — обычно скобки, которые показываются в браузерах, не поддерживающих ruby.
  - В браузерах с поддержкой ruby <rp> по умолчанию скрыт.
  - Вставляйте в него только символы‑обрамления или короткий текст.
  - Пример: <rp>(</rp><rt>かん</rt><rp>)</rp>

Дополнительные теги для сложной группировки
- <rb> (ruby base)
  - Явно помечает базовый текст (основной текст, к которому относится аннотация).
  - В простых случаях не обязателен (базовый текст может быть plain text), но полезен для читаемости и сложных структур.
  - Пример: <rb>明日</rb>

- <rbc> (ruby base container)
  - Группирует одну или несколько <rb>, когда нужно разбить базовую часть на логические блоки при сложных аннотациях.
  - Используется вместе с <rtc>.

- <rtc> (ruby text container)
  - Группирует одну или несколько <rt>, соответствующих <rbc>.
  - Нужен для сложных сопоставлений «несколько баз → несколько аннотаций» или когда аннотация охватывает несколько символов.
  - Пример комплексной структуры (сопоставление и группировка):

Простой случай (наиболее часто):
<ruby>
  漢<rp>(</rp><rt>かん</rt><rp>)</rp>
  字<rp>(</rp><rt>じ</rt><rp>)</rp>
</ruby>

С использованием <rb>/<rtc>/<rbc> для сложной группировки:
<ruby>
  <rbc>
    <rb>明</rb><rb>日</rb>
  </rbc>
  <rtc>
    <rt>あ</rt><rt>した</rt>
  </rtc>
</ruby>

Замечания по семантике и использованию
- Простая, наиболее совместимая разметка: base text + <rt>. <rb> обычно не нужен.
- <rp> нужен только как запасной (legacy) и обычно содержит "(" и ")".
- Не вкладывайте блочные элементы внутрь <ruby> — содержимое должно быть inline/phrasing.
- Не создавайте лишних вложенных <ruby> внутри другого <ruby> — это усложняет рендеринг.

Доступность и поведение скрин‑ридеров
- Поведение различных скрин‑ридеров/браузеров варьируется: некоторые читают rt подряд, другие вставляют скобки.
- Для критичной доступности можно добавить aria-label или скрытую текстовую альтернативу.
- Всегда тестируйте на целевых UA/скрин‑ридерах, если информация важна для понимания.

Стилизация (коротко)
- CSS‑свойства (Ruby Module) позволяют управлять позицией и выравниванием аннотаций, например ruby-position и ruby-align (поддержка может отличаться между браузерами).
- Учитывайте writing-mode (горизонтальная/вертикальная письменность) — браузеры меняют отрисовку ruby в зависимости от направления текста.

Советы и типичные ошибки
- Для старых браузеров всё ещё полезно включать <rp> как запасные скобки.
- Для HiDPI/вертикального текста тестируйте отображение — иногда нужен дополнительный CSS.
- Не полагайтесь на ruby для несущей семантики — при необходимости дублируйте важное через aria.

Поддержка браузеров
- Современные браузеры (Chrome, Firefox, Safari, Edge) поддерживают ruby‑аннотации; поведение в мелочах может отличаться (вертикальное позиционирование, выравнивание).
- Для совместимости используйте простую разметку и добавляйте <rp> как fallback.



==================================================
 Что значит HTML-тег <rp> и почему он так назван?
==================================================

Тег <rp> нужен для «скобок» вокруг ruby-анотаций (фуриганы и т. п.) и показывается только в браузерах, которые не поддерживают отрисовку ruby. Название rp расшифровывается как «ruby parenthesis» (ruby‑parentheses) — то есть «скобки для ruby».

Что делает <rp>
- Внутри <ruby> вы обычно вставляете <rt> (ruby text — аннотацию) и, опционально, <rp> вокруг символов‑скобок, например "(" и ")".
- В браузерах с поддержкой ruby <rp> по умолчанию скрыт (не отображается), потому что браузер сам разместит аннотацию над/под исходным текстом.
- В старых/неподдерживающих браузерах <rp> будет виден — даёт явно читаемые скобки вокруг аннотаций, чтобы не ломалась читаемость.

Простой пример:
<ruby>
  漢<rp>(</rp><rt>かん</rt><rp>)</rp>
  字<rp>(</rp><rt>じ</rt><rp>)</rp>
</ruby>

Альтернативная разметка с <rb> (ruby base):
<ruby>
  <rb>明日</rb>
  <rp>(</rp><rt>あした</rt><rp>)</rp>
</ruby>

Основные рекомендации
- Помещайте в <rp> только символы‑скобки или короткий текст‑замену (обычно "(" и ")").
- Не используйте <rp> для основной информации — это только резервный визуальный обрамляющий контейнер для неподдерживающих агентов.
- Тестируйте в браузерах и с вспомогательными технологиями; поведение скрин‑ридеров может различаться, поэтому при необходимости добавляйте aria-label или альтернативный текст.
- Для множественных подряд аннотаций используйте <rb> и <rt> корректно; <rtc> и <rbc> — для группирования сложных случаев (реже нужно).

Совместимость и поведение
- Элемент введён в HTML5; современные браузеры (Chrome/Edge/Firefox/Safari) поддерживают ruby и по умолчанию скрывают <rp>.
- Можно изменить стиль <rp> через CSS, но это может ломать ожидаемое поведение; обычно не нужно менять.

Готовые формулировки (для документации или комментариев)
- «<rp> — элемент для резервных скобок вокруг ruby-аннотаций; показывает скобки в UA, которые не поддерживают ruby.»
- «Используйте <rp> для улучшения отображения фуриганы в старых браузерах, помещая в него только скобки или короткие обрамляющие символы.»
